# Salesforce CRM - React + Spring Boot

Full Stack CRM Application

## Project Structure
saleforce/
├── frontend/     # React App - Port 3000
├── sf-backend/   # Spring Boot API - Port 8080
└── README.md

## How to Run

### Backend
cd sf-backend
./mvnw spring-boot:run

### Frontend  
cd frontend
npm install
npm start

## Tech Stack
Frontend: React, Tailwind, Axios
Backend: Spring Boot, JPA, MySQL, JWT
